# Relay 0.3 desktop

See [README.md](README.md) for setup, peer migration, and rollback; see [PEER-ARCHITECTURE.md](PEER-ARCHITECTURE.md) for networking and recovery.

The checksum-pinned VSCodium engine supplies native folders, terminals, Git tools, language services, and compatible extensions. Relay's extension supplies Invite, Join, Team, Live Changes, and direct shared-source synchronization.

Production Workspace Trust remains enabled. The classic cloud desktop is retained in the pre-migration backup and is not launched by 0.3.

Windows interactive testing remains a separate final step. A Linux build does not prove Windows behavior.
