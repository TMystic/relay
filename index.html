Extension compatibility

Relay currently uses Monaco, the code editor component used by VS Code. Monaco does not include VS Code's extension host.

Relay tools below run in this editor. Existing VS Code extensions need an extension host and the VS Code API; they cannot be installed here yet.

Full compatibility requires migrating to a VS Code-compatible workbench and connecting live collaboration to its document system.
