# Relay Collaboration

Relay adds live source collaboration to its full Code-OSS desktop editor. Open or create a folder, invite your team, and keep using the built-in terminal and extensions.

The Relay activity bar contains Team and Live Changes. Command Palette commands begin with **Relay:**. Invitations also work in the browser companion.

Source edits sync without Git push/pull. Folder sharing excludes dependency/build directories, `.git`, `.env` files, binaries, and symbolic links. This preview shares up to 1 MB of UTF-8 source across 1,000 files. Terminals execute locally and are never controlled by teammates. Installed extensions are local to your editor.

Use an empty destination folder when joining an existing room. Relay does not overwrite unrelated local files. Workspace Trust remains enabled. Compatible extensions come from Open VSX or locally supplied VSIX packages; some Microsoft-only extensions are unavailable in alternative editors.
